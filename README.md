## Aim
Apply NumPy to create a one-dimensional array containing the numbers from 1 to 10, perform slicing operations, compute statistical measures (sum, mean, maximum, and minimum), and apply broadcasting to modify the array elements.

## Problem Statement
Write a Python program using the `numpy` library to:
1. Generate a 1D NumPy array with integers from `1` to `10`.
2. Perform array slicing operations (first 5 elements, last 3 elements, middle slice, and every second element).
3. Compute core statistical metrics (`sum`, `mean`, `max`, and `min`).
4. Demonstrate NumPy broadcasting by applying scalar arithmetic transformations across the array elements.
